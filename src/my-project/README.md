# My Project

## Overview
This project analyzes evaluation results from various documents related to 3M and Activision Blizzard. It processes the data to generate insights and answers to specific financial questions.

## Project Structure
- `data/evaluation_results.json`: Contains the evaluation results in JSON format.
- `src/main.py`: The main script that processes the evaluation results.
- `requirements.txt`: Lists the required Python packages for the project.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   cd my-project
   ```

2. Install the required packages:
   ```
   pip install -r requirements.txt
   ```

## Usage
Run the main script to process the evaluation results:
```
python src/main.py
```
